# Travel Platform — Portfolio Case Study

A portfolio case study of an interactive travel video platform developed in 2022.

The platform brings together more than 1,000 travel videos from different TV programmes and allows users to explore destinations across Russia through regional search and an interactive map.

## My Role

Project Manager — responsible for:
- Defining user scenarios and functional requirements
- Coordinating editorial, design and development teams
- Organising content preparation and geographical metadata
- Coordinating implementation, testing and quality control

## Key Features

- Search for destinations by region
- Dedicated pages with videos related to each region
- Interactive map with geographical video markers
- Related videos that help users explore more content from the same region
